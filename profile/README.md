# Ritru

Ritru is building the operating system for AI-assisted software delivery.

We create secure AI engineering products and productised services that help teams design, build, deploy, operate, and improve software with less repetitive human effort.

## Focus

- AI engineering agents and agentic platforms
- developer tools, CLIs, SDKs, and workflow automation
- cloud, Kubernetes, DevOps, and platform engineering
- software supply-chain and release automation
- observability and operational intelligence
- enterprise AI adoption and automation

## How we build

Ritru combines specialised AI agents with deterministic tools, policy controls, human approval, least-privileged execution, validation, audit evidence, and rollback.

We optimise for reliable customer outcomes and reusable product capability—not billable headcount or one-off scripts.
