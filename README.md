# Ritru GitHub Organisation Standards

This repository defines shared GitHub defaults, contribution controls, repository bootstrap requirements, and the organisation profile for Ritru Labs.

Ritru is an AI-first technology company building secure automation for software engineering, cloud platforms, Kubernetes, developer productivity, and enterprise AI.

## Responsibilities

- publish the Ritru organisation profile;
- provide shared issue and pull-request templates;
- define repository, branch, merge, security, and AI-assisted change standards;
- provide repeatable bootstrap and release-readiness checklists;
- keep organisation-wide defaults small, stable, and broadly applicable.

## Precedence

The [Ritru handbook](https://github.com/ritru-labs/handbook) is the company operating system and source of governing principles. Repository-specific rules may strengthen these defaults where risk or product needs require it. Exceptions must be explicit, owned, justified, and time-bounded.

## Operating principles

> Build reusable systems, not collections of scripts.

> Automate the delivery system before adding delivery headcount.

AI may accelerate analysis, generation, testing, and documentation. It does not replace accountable ownership, deterministic validation, security controls, approval, evidence, or recovery.
